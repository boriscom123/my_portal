# Как подключить Instagram

Портал будет выкладывать вертикальные ролики в Reels. Всё, что здесь описано,
делается один раз.

Сразу поправка к тому, что я говорил раньше: **страница в Facebook не нужна**.
Она нужна только на другом пути подключения — через вход по Facebook. Мы идём
через вход по самому Instagram, и там достаточно аккаунта Instagram.

## 1. Профессиональный аккаунт

Личный аккаунт через API не публикуется вовсе. Переключение бесплатное и
обратимое, подписчики и записи остаются на месте.

В приложении Instagram: **Настройки → Тип аккаунта и инструменты → Переключиться
на профессиональный аккаунт**. Тип — **Автор** (Creator); он для тех, кто
выпускает контент от своего имени, в отличие от «Бизнеса» для магазинов и услуг.

Проверить, что получилось: в профиле появится раздел «Профессиональная панель».

## 2. Приложение Meta

1. https://developers.facebook.com → войти тем аккаунтом, которым вы пользуетесь.
   Если это первый вход, площадка попросит подтвердить телефон и принять условия
   разработчика.
2. **My Apps → Create App**.
3. Тип приложения — **Business**. Другой тип потом не поменять, придётся заводить
   новое.
4. Имя приложения — любое понятное вам, например `Solo AI Journey`. Оно
   показывается на экране согласия, когда вы разрешаете порталу доступ.

## 3. Продукт Instagram

В приложении: **Add product → Instagram → Set up**, и внутри выбрать
**Instagram API setup with Instagram Login** — это тот путь, где не нужна
страница Facebook.

Дальше в разделе **Instagram → API setup with Instagram Login**:

**Шаг 1. Generate access tokens.** Здесь кнопка **Add account** — привяжите свой
аккаунт Instagram, тот самый профессиональный.

**Шаг 2. Set up Instagram business login.** Нужен адрес возврата — портал ждёт
его ровно таким:

```
https://soloaijourney.online/api/integrations/instagram/callback
```

Впишите его в поле **Redirect URI** до последнего знака: площадка сверяет его
посимвольно и на расхождение отвечает отказом, не объясняя, каким именно.

Рядом два поля обратных вызовов — **Deauthorize callback URL** и **Data deletion
request URL**. Площадка требует их заполнить. Впишите:

```
https://soloaijourney.online/api/integrations/instagram/deauthorize
https://soloaijourney.online/api/integrations/instagram/delete
```

Эти два адреса портал сделает вместе с самой выкладкой — этап 8б.

## 4. Права

В том же разделе, в списке разрешений, нужны два:

| Разрешение | Зачем |
|---|---|
| `instagram_business_basic` | узнать, чей это аккаунт |
| `instagram_business_content_publish` | выложить ролик |

**Проверка приложения (App Review) для вашего собственного аккаунта не нужна.**
Она нужна, чтобы публиковать чужие аккаунты — а вы публикуете свой, и он привязан
к приложению шагом выше. Если в панели у разрешения написано «Advanced Access
required» — значит, оно запрошено для чужих аккаунтов; нам нужен уровень
**Standard Access**.

## 5. Что прислать мне

Из раздела **App settings → Basic**:

- **Instagram App ID**
- **Instagram App Secret** (кнопка «Show»)

Пришлите их — я вставлю в настройки портала, там для этого будет свой раздел,
как у YouTube. В репозиторий и в переписку они не попадут: портал хранит их
зашифрованными.

## Про сроки жизни доступа

Доступ Instagram выдаёт на **60 дней**, и его надо продлевать. Портал будет
делать это сам, пока хотя бы раз в два месяца что-то выкладывает. Если раздел
простоит без дела дольше двух месяцев, доступ придётся выдать заново — нажатием
той же кнопки в настройках.

## Пределы площадки

- 100 публикаций в сутки — нам хватит стократно.
- Ролик площадка забирает по ссылке с портала сама; ссылка временная и
  подписанная, чужой по ней ничего не достанет.
