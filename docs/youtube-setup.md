# Как подключить канал YouTube

Портал заливает на канал запись, субтитры и обложку. Открыть ролик придётся
вам — почему, объяснено в конце.

Всё, что здесь описано, делается один раз.

## 1. Проект в Google Cloud

Заведите **отдельный** проект — не тот, где живёт вход на портал через Google.
Проверку (compliance audit) Google проводит по проекту, и мешать в одном экране
согласия вход на сайт и доступ к каналу не стоит: заявку читает человек.

1. https://console.cloud.google.com → «Создать проект», имя любое.
2. «APIs & Services» → «Library» → найти **YouTube Data API v3** → «Enable».

## 2. Экран согласия

**Google переименовал этот раздел.** «APIs & Services → OAuth consent screen»
больше нет: теперь это отдельный раздел **Google Auth Platform** (меню слева или
поиск сверху по словам «Auth Platform»). В новом проекте там будет кнопка
«Get started».

Внутри четыре вкладки, и нужны три из них.

**Branding.** Имя приложения, ваша почта поддержки, ниже — контакт разработчика.
Здесь же блок «App domain», и без него приложение не перевести в рабочий режим:

| Поле | Что вписать |
|---|---|
| Application home page | `https://ваш-домен` |
| Application privacy policy link | `https://ваш-домен/privacy` |
| Application terms of service link | `https://ваш-домен/terms` |
| Authorized domains | `ваш-домен` |

Обе правовые страницы у портала есть — Google по ним ходит и проверяет, что они
открываются без входа.

**Audience.** User type — **External**. Ниже «Test users» → «Add users» → ваша
почта, та самая, которой принадлежит канал.

**Data Access.** «Add or remove scopes» → в фильтре `youtube.force-ssl` →
отметить `.../auth/youtube.force-ssl` → Update → Save. Google предупредит, что
область доступа чувствительная. Так и есть — ради неё и нужен аудит из раздела 8.

### Обязательно: перевести приложение в рабочий режим

На вкладке **Audience** нажмите **«Publish app»**, чтобы «Publishing status»
стал «In production».

Это не косметика. Пока приложение числится тестовым, **Google убивает доступ
через семь дней** — портал будет терять канал каждую неделю, и узнаете вы об
этом неудачной выкладкой. В рабочем режиме доступ живёт, пока им пользуются.

При подключении Google один раз покажет «Google hasn't verified this app» —
это ожидаемо для непроверенного приложения: «Advanced» → «Go to … (unsafe)».
С аудитом, который снимает принудительную приватность роликов, это никак не
связано: проверки разные.

Если Google отвечает **«Ошибка 403: access_denied»** и пишет про тестировщиков —
значит приложение осталось тестовым, а вашей почты нет в списке. Проще не
добавлять почту, а нажать «Publish app».

Если **«Publish app» не нажимается** и Google просит дозаполнить Branding —
вернитесь к таблице выше: обычно не заполнены правовые ссылки или Authorized
domains.

## 3. Учётные данные

«APIs & Services» → «Credentials» → «Create credentials» → «OAuth client ID»:

- тип **Web application**;
- «Authorized redirect URIs» → вставить адрес возврата.

Адрес не выдумывайте: портал показывает его готовой строкой на странице
«Настройки» → «Площадки». Скопируйте оттуда до последнего знака — лишний слэш в
конце даёт `redirect_uri_mismatch` и час поисков.

Скопируйте Client ID и Client secret.

## 4. Ключи — в кабинете

**Настройки** → **Площадки** → YouTube:

- Client ID — из консоли Google;
- Client secret — оттуда же. Портал его шифрует и больше никогда не
  показывает: при следующей правке поле будет пустым, и пустым его можно
  оставить — сохранённый секрет от этого не потеряется;
- «Что делать с роликом» — пока приложение не прошло проверку Google, оставьте
  «оставлять приватным»: второй вариант площадка всё равно не выполнит.

Сохранить. После этого появится кнопка подключения канала.

Переменные `YOUTUBE_*` в `.env` больше не нужны. Если они там есть, портал
возьмёт их как запасной вариант — на случай, если в кабинете ничего не заведено.

## 5. Подключение

«Настройки» → «Площадки» → «Подключить канал» → выбрать аккаунт канала →
разрешить доступ. Та же кнопка есть на странице загрузки.

Отключить канал можно там же: токены забудутся, а ключи приложения останутся —
заводить их заново ради смены аккаунта незачем.

Токен доступа живёт час и обновляется сам; портал хранит его в базе
зашифрованным.

## 6. Выкладка

Экран урока → раздел «Площадки» → «Отправить на YouTube».

Уезжает смонтированная запись, если вы её собрали, иначе исходник. Субтитры
идут в пару **именно к тому файлу**, который уехал. Обложка — та, что выбрана в
карточке; тяжелее 1.9 МБ она пережимается, потому что предел площадки 2 МБ.

Когда заливка кончится, придёт уведомление на телефон.

## 7. Почему ролик приватный

Ролики, загруженные через API приложением, не прошедшим проверку Google,
**принудительно остаются приватными**. Поле «сделать публичным» при загрузке
игнорируется — это правило для всех проектов, заведённых после 28 июля 2020.

Поэтому портал доводит дело до конца, а последнее нажатие остаётся за вами:

1. в кабинете под роликом — ссылка «открыть ролик», она ведёт в студию;
2. открываете доступ там;
3. возвращаетесь на экран урока и жмёте «Проверить».

Портал спросит у площадки приватность ролика и, если он публичный, поставит
ссылку на страницу урока. До этого ссылка зрителю не показывается: приватный
ролик чужому человеку не открывается, и кнопка вела бы в никуда.

## 8. Заявка на проверку

Проверка снимает принудительную приватность. Подаётся из «APIs & Services» →
«YouTube Data API» → форма аудита. В заявке описывают сценарий (портал автора
заливает собственные уроки на собственный канал), показывают экран согласия и
соглашаются с условиями YouTube API Services. Обычно это недели.

Когда проверка пройдена, в настройках меняется **один** выбор: «публиковать
сразу». После него ролик уезжает публичным, ссылка встаёт в карточку без вашего
участия, а кнопка «Проверить» перестаёт показываться. Кода это не касается.

## Что делать, если не вышло

| Что видно | Причина |
|---|---|
| `redirect_uri_mismatch` на экране Google | адрес в Google Cloud отличается от показанного в настройках |
| «Канал YouTube не подключён» при выкладке | подключение не проходило или токен отозван — подключите заново в настройках |
| «Суточная норма загрузок исчерпана» | норма 100 загрузок в сутки; это не поломка |
| «обложка не встала» рядом с готовым роликом | канал не подтверждён по телефону либо картинка не принята; ролик при этом на канале |
| Ролик на канале, а ссылки на портале нет | ролик ещё приватный — откройте его в студии и нажмите «Проверить» |
