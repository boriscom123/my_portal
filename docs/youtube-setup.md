# Как подключить канал YouTube

Портал заливает на канал запись, субтитры и обложку. Открыть ролик придётся
вам — почему, объяснено в конце.

Всё, что здесь описано, делается один раз.

## 1. Проект в Google Cloud

Заведите **отдельный** проект — не тот, где живёт вход на портал через Google.
Проверку (compliance audit) Google проводит по проекту, и мешать в одном экране
согласия вход на сайт и доступ к каналу не стоит: заявку читает человек.

1. https://console.cloud.google.com → «Создать проект», имя любое.
2. «APIs & Services» → «Library» → найти **YouTube Data API v3** → «Enable».

## 2. Экран согласия

«APIs & Services» → «OAuth consent screen»:

- тип **External**;
- название приложения, ваша почта для связи;
- область доступа — **одна**: `https://www.googleapis.com/auth/youtube.force-ssl`.
  Она покрывает и загрузку ролика, и субтитры, и обложку;
- в «Test users» добавьте себя — тот аккаунт, которому принадлежит канал.

Пока приложение в тестовом режиме, доступ работает только для тестовых
пользователей. Для канала одного автора этого достаточно.

## 3. Учётные данные

«APIs & Services» → «Credentials» → «Create credentials» → «OAuth client ID»:

- тип **Web application**;
- «Authorized redirect URIs» → добавить
  `https://ваш-домен/api/integrations/youtube/callback`

Адрес возврата должен совпадать с тем, что ляжет в `.env`, **до последнего
знака**: лишний слэш в конце — и Google откажет с `redirect_uri_mismatch`.

Скопируйте Client ID и Client secret.

## 4. Настройки портала

В `.env` на сервере:

```bash
YOUTUBE_CLIENT_ID=<из Google Cloud>
YOUTUBE_CLIENT_SECRET=<из Google Cloud>
YOUTUBE_REDIRECT_URI=https://ваш-домен/api/integrations/youtube/callback
YOUTUBE_MODE=semi
```

Перезапустить приложение и воркер:

```bash
docker compose up -d api worker
```

Без этих ключей портал работает как прежде: раздел «Площадки» на экране урока
говорит, что площадка не настроена, и ничего не предлагает.

## 5. Подключение

Кабинет → «Загрузка» → «Подключить YouTube» → выбрать аккаунт канала →
разрешить доступ. Вернётесь на страницу загрузки с надписью «Канал подключён».

Токен доступа живёт час и обновляется сам; портал хранит его в базе
зашифрованным.

## 6. Выкладка

Экран урока → раздел «Площадки» → «Отправить на YouTube».

Уезжает смонтированная запись, если вы её собрали, иначе исходник. Субтитры
идут в пару **именно к тому файлу**, который уехал. Обложка — та, что выбрана в
карточке; тяжелее 1.9 МБ она пережимается, потому что предел площадки 2 МБ.

Когда заливка кончится, придёт уведомление на телефон.

## 7. Почему ролик приватный

Ролики, загруженные через API приложением, не прошедшим проверку Google,
**принудительно остаются приватными**. Поле «сделать публичным» при загрузке
игнорируется — это правило для всех проектов, заведённых после 28 июля 2020.

Поэтому портал доводит дело до конца, а последнее нажатие остаётся за вами:

1. в кабинете под роликом — ссылка «открыть ролик», она ведёт в студию;
2. открываете доступ там;
3. возвращаетесь на экран урока и жмёте «Проверить».

Портал спросит у площадки приватность ролика и, если он публичный, поставит
ссылку на страницу урока. До этого ссылка зрителю не показывается: приватный
ролик чужому человеку не открывается, и кнопка вела бы в никуда.

## 8. Заявка на проверку

Проверка снимает принудительную приватность. Подаётся из «APIs & Services» →
«YouTube Data API» → форма аудита. В заявке описывают сценарий (портал автора
заливает собственные уроки на собственный канал), показывают экран согласия и
соглашаются с условиями YouTube API Services. Обычно это недели.

Когда проверка пройдена, в `.env` меняется **одна** строка:

```bash
YOUTUBE_MODE=auto
```

После неё ролик уезжает сразу публичным, ссылка встаёт в карточку без вашего
участия, а кнопка «Проверить» перестаёт показываться. Кода это не касается.

## Что делать, если не вышло

| Что видно | Причина |
|---|---|
| `redirect_uri_mismatch` на экране Google | адрес возврата в `.env` и в Google Cloud различаются |
| «Канал YouTube не подключён» при выкладке | подключение не проходило или токен отозван — подключите заново |
| «Суточная норма загрузок исчерпана» | норма 100 загрузок в сутки; это не поломка |
| «обложка не встала» рядом с готовым роликом | канал не подтверждён по телефону либо картинка не принята; ролик при этом на канале |
| Ролик на канале, а ссылки на портале нет | ролик ещё приватный — откройте его в студии и нажмите «Проверить» |
