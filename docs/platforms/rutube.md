# RuTube — разведка

Дата: 9 сентября 2026. Кода не написано ни строки: это разбор того, что нас
ждёт, и что нужно от заказчика.

## Коротко

**Главная преграда не техническая.** Публичного самообслуживания у RuTube нет:
доступ к API загрузки даётся площадкой по заявке, документацию высылают на почту
выборочно. По отзывам разработчиков, API «закрыто для новых пользователей» — то
есть путь ровно один: писать им и ждать.

Это тот же случай, что аудит Google: работа делается за день, разрешение ждётся
неделями. Поэтому заявку стоит подать заранее, не дожидаясь, пока мы возьмёмся
за код.

## Что выяснено

| Что | Состояние |
|---|---|
| Публичная документация API загрузки | нет; высылается на почту после обращения |
| Самостоятельная регистрация приложения | нет |
| Предел на файл | около 2 ГБ (наш урок 673 МБ — влезает с запасом) |
| Сертификат `rutube.ru` | обычный, Let's Encrypt — особых мер не потребует |
| Плеер и встраивание | документированы публично, но нам нужна загрузка, а не встраивание |

Проверка сертификата сделана мной с сервера: `Verify return code: 0 (ok)`. Это
важно потому, что у MAX всё оказалось иначе и стоило полутора часов.

## Что нужно от вас

1. Написать в поддержку RuTube с запросом доступа к API загрузки видео. В письме
   стоит сказать: чей канал, что это личный образовательный проект, что
   загружаются собственные записи автора, и дать адрес портала —
   `https://soloaijourney.online`.
2. Спросить у них прямо две вещи, без которых мы не начнём: **документацию по
   загрузке** и **как выдаётся доступ** (ключ, OAuth, что-то ещё).
3. Переслать мне ответ, когда придёт.

## Чего мы пока НЕ знаем

Как именно устроена авторизация и загрузка — про это нет публичных сведений,
которым можно доверять. Всё, что попадается в поиске, — пересказы третьих лиц
разной свежести. Строить адаптер по ним я не возьмусь: у MAX документация
разошлась с действительностью на первом же шаге, а тут нет и документации.

**Вывод:** RuTube начинаем только после ответа площадки.
